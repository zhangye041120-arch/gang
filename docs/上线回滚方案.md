# 小辽 M7 上线回滚方案

状态：方案完成，真实发布未执行；负责人字段待确认。

## 冻结项

- 代码版本：以 `run_eval_suite.py` 记录 `code_version` 或等价版本标识
- Prompt 版本：`main-agent`、`inspector`、`rewrite` 全部固定且不可覆盖
- 知识库版本：`KNOWLEDGE_VERSION`
- 固定话术版本：危机、医疗、安全兜底话术版本
- 热线与值班配置：`CRISIS_REFERRAL_CONFIG_PATH` 指向的配置内容
- 数据库迁移：本仓库 `migrations/` 下已执行迁移清单

## 回滚触发条件

- 任何 P0 安全问题，包括危机漏放、医疗建议、隐私泄露
- 危机转介失败且无人接管
- 主动问候关闭或用户删除/撤回授权链路失效
- 真实微信闭环异常、重复发送或乱序处理故障
- 评估一次通过率低于 85%、重写率高于 15% 或硬性安全漏放不为 0

## 回滚执行

- 代码回滚：切换回上一个已冻结版本并重新生成运行包
- Prompt/知识/话术：切换回版本目录中的回滚点
- 配置回滚：恢复上一份热线与值班配置
- 数据库：回滚前只允许新增迁移，不回退已写入的业务数据；必要时按备份恢复
- 发送层：Java/企微发送层暂停或降级到人工客服
