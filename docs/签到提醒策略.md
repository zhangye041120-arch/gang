# 小辽 M7 企微员工群每日签到提醒

状态：功能已实现并默认关闭，真实企微联调待执行。

## 适用场景

目标是企业微信内部员工群，成员是企业微信员工。提醒通过“群机器人
（消息推送）Webhook”发送，不经过微信客服通道，因此不受微信客服
“用户主动发消息后 48 小时内最多回复 5 条”的限制，可以每天定时发送。

群机器人 Webhook 官方限制为每个机器人每分钟最多 20 条；每日签到提醒
频率远低于该限制。

## 签到的产品定位（来自 PRD）

M1 每日签到与情绪天气：留存入口 + 情绪追踪。签到提醒是“固定线索”，
目的是帮助老人养成每天打开并记录情绪的习惯，不是强制考勤。

- 签到是“情绪天气”记录，不签到也能使用其他功能，避免压力。
- 提醒语使用温和、不催促的措辞，签到后给即时正向反馈。
- 签到日期、情绪值、连续天数、签到时段会写入数据；连续 3 天负面情绪
  触发 M7 客服温和关怀策略。

## 配置项

| 配置 | 默认值 | 说明 |
|---|---|---|
| `WECOM_CHECKIN_REMINDER_ENABLED` | `false` | 全局开关，默认关闭 |
| `WECOM_CHECKIN_GROUP_WEBHOOK` | 空 | 群机器人 Webhook 地址 |
| `WECOM_CHECKIN_GROUP_WEBHOOK_SECRET` | 空 | 机器人启用“加签”时的密钥 |
| `WECOM_CORP_ID` | 空 | 企业微信 CorpID，用户级私信必填 |
| `WECOM_AGENT_ID` | 空 | 自建应用 AgentId，用户级私信必填 |
| `WECOM_AGENT_SECRET` | 空 | 自建应用 Secret，用户级私信必填 |
| `WECOM_CHECKIN_GROUP_TIMES` | `09:00` | 每日提醒时间，支持多个，逗号分隔 |
| `WECOM_CHECKIN_GROUP_MESSAGE` | 温和签到文案 | 提醒正文，默认不催促 |
| `WECOM_CHECKIN_GROUP_MENTION_ALL` | `false` | 群统一时间是否提醒全员 |
| `WECOM_CHECKIN_GROUP_MENTIONED_USERS` | 空 | 群统一时间指定 userid，逗号分隔 |
| `WECOM_CHECKIN_GROUP_MENTIONED_MOBILES` | 空 | 群统一时间指定手机号，逗号分隔 |
| `WECOM_CHECKIN_GROUP_CATCH_UP_MINUTES` | `15` | 服务短暂停机后的补发窗口 |
| `WECOM_CHECKIN_GROUP_STATE_PATH` | 空 | 幂等状态持久化路径，建议生产填写 |
| `WECOM_CHECKIN_GROUP_USER_SCHEDULE_PATH` | 空 | 用户级习惯时间 JSON 路径 |

## 用户级习惯时间

配置 `WECOM_CHECKIN_GROUP_USER_SCHEDULE_PATH` 后，系统按每个用户自己的
时间点提醒：到点通过企业微信自建应用消息给用户发送私信，不在群里 @ 用户。
幂等键变为“用户 + 日期 + 时间点”。用户级配置存在时，
`WECOM_CHECKIN_GROUP_TIMES` 的群统一时间不再发送，避免重复打扰。

JSON 格式参考 `checkin_user_schedule.example.json`：

```json
{
  "users": [
    {
      "user_id": "zhangsan",
      "times": ["08:00"]
    },
    {
      "user_id": "lisi",
      "times": ["09:30", "15:00"]
    }
  ]
}
```

- 每个条目必须填写企业微信成员 `user_id`，应用消息私信按该 ID 发送。
- `times` 支持多个时间点，格式为 `HH:MM`。
- 使用用户级私信前必须配置 `WECOM_CORP_ID`、`WECOM_AGENT_ID`、
  `WECOM_AGENT_SECRET`。
- 未配置用户级时间表时，回退到 `WECOM_CHECKIN_GROUP_TIMES` 的群统一时间。

## 发送逻辑

- 服务每 60 秒检查一次当前北京时间是否到达配置的时间点。
- 到达时间点后 15 分钟内（可配置）只发送一次，避免重复提醒。
- 群统一时间幂等键为“发送日期 + 时间点”；用户级时间为
  “用户 + 发送日期 + 时间点”，同一天同一时间点不会重复发送。
- 发送失败不标记为已完成，下一个调度周期在补发窗口内自动重试。
- `WECOM_CHECKIN_GROUP_STATE_PATH` 留空时使用进程内内存；生产建议填写
  本地 SQLite 路径，例如 `运行/checkin_reminder_state.sqlite3`，防止重启后重复发送。
- 全局开关默认关闭；未配置 Webhook 时直接返回 `blocked`，不会发起请求。

## 安全要求

- Webhook 地址等同于机器人密钥，禁止提交到 Git 或分享到公开位置。
- 建议在群机器人安全设置中启用“加签”，并填写
  `WECOM_CHECKIN_GROUP_WEBHOOK_SECRET`。
- 机器人只发送内部员工群；如果群内混入外部联系人，请改用企业微信应用消息方案。

## 联调步骤

1. 在企微管理后台添加“群机器人”（群统一时间用），并准备自建应用凭据
   `WECOM_CORP_ID` / `WECOM_AGENT_ID` / `WECOM_AGENT_SECRET`（用户级私信用）。
2. 如启用“加签”，把机器人密钥填入
   `WECOM_CHECKIN_GROUP_WEBHOOK_SECRET`。
3. 在 `.env` 中开启：

```env
WECOM_CHECKIN_REMINDER_ENABLED=true
WECOM_CHECKIN_GROUP_WEBHOOK=https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=...
WECOM_CORP_ID=your_corp_id
WECOM_AGENT_ID=your_agent_id
WECOM_AGENT_SECRET=your_agent_secret
WECOM_CHECKIN_GROUP_TIMES=09:00
WECOM_CHECKIN_GROUP_STATE_PATH=运行/checkin_reminder_state.sqlite3
WECOM_CHECKIN_GROUP_USER_SCHEDULE_PATH=checkin_user_schedule.example.json
```

4. 手动触发一次真实发送验证：

```bash
python 运行/run_checkin_reminder.py --once
```

5. 验证群里收到消息后，启动 API 服务进入每日自动调度。
