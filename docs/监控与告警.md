# 小辽 M7 监控与告警定义

本文件是监控方案定义，不是“生产监控已上线”的声明。当前交付脚本看板：`python metrics_dashboard.py`；真实平台接入和阈值确认完成前，告警规则保持“待确认”。

## 指标定义

生产 API 在 service-token 鉴权的 `/metrics` 暴露以下 Prometheus 指标；标签只允许
method、路由模板、状态码、固定阶段/结果/依赖名，不允许 user_id、session_id、
message、memory content 或 token：

- `xiaoliao_http_requests_total`
- `xiaoliao_http_request_duration_seconds`
- `xiaoliao_agent_stage_duration_seconds`
- `xiaoliao_model_errors_total`
- `xiaoliao_idempotency_total`
- `xiaoliao_dependency_unavailable_total`
- `xiaoliao_memory_operations_total`
- `xiaoliao_memory_cache_total`
- `xiaoliao_crisis_events_total`

HTTP/SSE 时长在最后一个响应 chunk 发送时记录。应用日志为单行 JSON，固定含
`request_id`、路由模板、状态、耗时和错误码，不含请求/响应正文。

| 指标 | 定义 | 数据来源 |
|---|---|---|
| 一次通过率 | 评估运行中全部机器断言通过的比例 | `eval_runs/*/results.json` |
| 重写率 | 非拦截用例中 rewritten=true 的比例 | AgentResult / inspection_logs |
| 拦截率 | 评估运行中 blocked=true 的比例 | 评估结果 |
| 硬性安全漏放 | 高风险输入未 blocked 或未置安全标志 | 评估结果 / 危机日志 |
| 误拦截候选 | 正常输入被 blocked 的数量 | 评估结果 |
| RAG 命中率 | sources 非空的比例 | 评估结果 |
| p50/p95 延迟 | 完成用例延迟分位 | 评估结果 / inspection_logs |
| 模型成功率 | error_code 为空的完成比例 | 评估结果 / inspection_logs |
| token 与费用 | 输入/输出/总 token 与估算费用 | direct 模式记录；HTTP 模式无 token 时标记缺失 |

同类错误周环比只在存在两周可比数据时计算；只有一周数据时输出 `not_enough_history`，不生成环比结论。

## 告警规则

规则定义见 [monitoring/alert_rules.json](../monitoring/alert_rules.json)。所有阈值当前为“待确认”，原因：

- 生产预算和费用上限尚未由负责人书面确认。
- p95 延迟目标需要结合灰度用户真实网络和模型波动确认；当前基线 case_09 为 19.9s。
- 队列积压、5xx 比例和知识库降级比例需要真实平台监控基期。

## 日志查询

质量日志表为 `ai_inspection_logs`，字段含 `request_id`、`message_id`、`latency_ms`、`main_model`、`inspector_model`、`prompt_version`、`error_pattern`、`issues`、`input_tokens`、`output_tokens`、`total_tokens`、`cost`。数据库不可达时，先使用脚本看板读取 `eval_runs`，并记录降级告警。

示例查询（数据库可用后）：

```sql
SELECT error_pattern, count(*) AS cnt, round(avg(latency_ms)) AS avg_latency_ms
FROM ai_inspection_logs
WHERE created_at >= now() - interval '24 hours'
GROUP BY error_pattern
ORDER BY cnt DESC;
```

## 脚本看板

```bash
python metrics_dashboard.py
```

输出当前 `eval_runs` 下每次运行的 run_id、状态、一次通过率、硬性安全漏放、p50/p95 延迟、token 和费用缺失标记。该脚本只读取本地不可变运行目录，不冒充生产监控。
