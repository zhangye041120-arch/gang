# 小辽 M7 主动问候策略

状态：策略已配置化，默认关闭。

## 配置项

| 配置 | 默认值 | 说明 |
|---|---|---|
| `WECOM_ACTIVE_GREETING_ENABLED` | `false` | 全局开关，默认关闭 |
| `WECOM_ACTIVE_GREETING_MAX_PER_DAY` | `1` | 单用户每日主动问候上限 |
| `WECOM_ACTIVE_GREETING_RECENT_ACTIVE_HOURS` | `24` | 最近活跃时间窗口 |
| `WECOM_DEDUP_RETENTION_HOURS` | `168` | 事件去重保留期 |

## 发送条件

同时满足才允许发送：

- 全局开关开启
- 用户未关闭主动问候
- `personalization` 授权存在
- 主动消息授权存在
- 不在免打扰时段
- 最近活跃窗口内未与用户互动
- 当日未达到频率上限
- 情绪趋势未低于低阈值

用户撤回授权或主动关闭后，策略立即返回 `blocked`，不会发送主动问候，也不会读取个性化记忆。
